# Python IA

Repositorio con actividades, ejercicios y proyectos desarrollados durante la asignatura **Python para Inteligencia Artificial** de mi maestría en Inteligencia Artificial.

Aunque la materia está orientada a la comprensión y aplicación de Python, gran parte del trabajo se enfoca en la manipulación, limpieza, análisis y visualización de datos utilizando herramientas ampliamente utilizadas en ciencia de datos.

Este repositorio también sirve como evidencia de mis conocimientos y experiencia en análisis de datos, mostrando diferentes técnicas y procesos aplicados a conjuntos de datos reales y académicos.

## Objetivos

- Fortalecer el uso de Python para análisis de datos.
- Aplicar procesos de limpieza y transformación de datos.
- Realizar análisis exploratorios de datos (EDA).
- Crear visualizaciones para interpretar información.
- Documentar el proceso de aprendizaje dentro de la maestría.

## Tecnologías Utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Temas Desarrollados

Entre las actividades del repositorio se encuentran:

- Carga y exploración de datos.
- Limpieza y preparación de datasets.
- Tratamiento de valores nulos y datos inconsistentes.
- Análisis descriptivo.
- Visualización de datos mediante gráficos.
- Manipulación de datos con Pandas.
- Ejercicios prácticos orientados a la analítica de datos.
